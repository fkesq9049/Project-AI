# Simple Delivery ETA Predictor

Final project for the Building AI course

## Summary

Building AI course project: My project predicts when a truck delivery or package will arrive at its destination. It uses past delivery logs, traffic and weather data to give more accurate arrival times and reduce waiting.

## Background

Deliveries are often delayed by traffic or bad weather, which causes extreme waiting times. I have waited many hours for delayed packages, which is exhausting. This project helps to estimate actual delivery times better and reduce waiting.

## How is it used?

Logistics dispatchers use the program in the morning to plan the routes, and drivers check it during the day to see the updated arrival times.

## Data sources and AI methods

It needs historical delivery logs, real-time traffic updates, weather conditions, and GPS location data. I would use machine learning (regression) that learns from past deliveries to predict the arrival time.

## Challenges

The project can't predict road accidents, which happen instantly, unexpected truck breakdowns, or extreme weather events that can't be predicted in real time.

## What next?

The next step is to write a simple Python script using open traffic data, test it on a local delivery route, and improve it over time with feedback.
